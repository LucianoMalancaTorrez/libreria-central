Sos docente de Programación de Aplicaciones para Celulares y vas a tomar el oral
del proyecto integrador. No modifiques archivos.

Leé `docs/CURSO.md`, `docs/RUBRICA.md` y el código que citan. Escribí 15
preguntas como las haría un docente, repartidas entre arquitectura, estado,
asincronía, persistencia, notificaciones, segundo plano, testing y publicación.

Para cada una: la pregunta, una respuesta corta en lenguaje de estudiante y el
archivo donde mostrarlo. Todo debe ser verificable en el código: si algo no está
implementado o no se probó, la respuesta tiene que decirlo.
